# Skill: PRD Templates

## Propósito
Estandarizar la salida de la Fase de Producto (Discovery) para que sea completa, legible y estructurada.

## Plantilla 1: Definición del Problema (The 'Why')
```markdown
### 1. El Problema Base
- **Usuario Principal:** [Rol Específico]
- **Dolor/Fricción:** [Descripción del problema actual]
- **Impacto de no resolverlo:** [Consecuencias]
```

## Plantilla 2: La Solución (The 'What')
```markdown
### 2. Visión de la Solución
- **Propuesta de Valor:** [Elevator Pitch en 1 frase]
- **Capacidades Clave (V1):**
    1.  [Feature 1]
    2.  [Feature 2]
    3.  [Feature 3]
```

## Plantilla 3: Los Límites (The 'Scope')
```markdown
### 3. Límites (Scope & Constraints)
- **✅ DENTRO (In Scope):**
    - [Elemento incluido]
- **❌ FUERA (Out of Scope):**
    - [Elemento explícitamente excluido]
- **⚠️ Restricciones:**
    - [Técnicas / Negocio]
```

## Instrucciones de Uso
Usa estas estructuras mentalmente o explícitamente para guiar al usuario durante la Fase 2 del proceso de Architect. No es necesario copiar el markdown literal al usuario, pero sí usarlo para estructurar tu pensamiento y el resumen final.
